# 05 - spray_combust_3d：喷雾燃烧（PeleLMeX 单GPU）

## 目标
验证 PeleLMeX + GPU + 喷雾 + 反应的可行性

## 基础配置
| 项目 | 设置 |
|------|------|
| 求解器 | PeleLMeX（低马赫） |
| 并行 | **单 GPU** (USE_CUDA=TRUE) |
| 化学 | ReactorRK64（显式） |
| 域 | 2×2×2 cm |

## 调试历程

### 阶段 1：EB + 喷雾定位
| 组合 | 结果 |
|------|------|
| EB+反应 无喷雾 | ✅ 正常 |
| 喷雾+反应 无EB | ✅ 正常 |
| **EB+喷雾** | ❌ CUDA error 700 |

**结论**：PeleLMeX GPU 不支持 EB+喷雾组合。去掉 EB。

### 阶段 2：decane_3sp + RK64
| 尝试 | 网格 | 初温 | CFL | 步数 | 结果 |
|------|------|------|-----|------|------|
| 1 | 64³ | 1500K | 0.5 | 141 | ❌ NaN |
| 2 | 64³ | 1000K | 0.1 | 218 | ❌ NaN |
| 3 | 32³ | 1000K | 0.05 | 226 | ❌ NaN |

**结论**：CFL 降低几乎无效果。发现 **decane_3sp 是无反应机理**（只有蒸发，没有燃烧！）

### 阶段 3：heptane_3sp + RK64
- 换机理后同样崩
- **发现 heptane_3sp 也无反应式**——这些是蒸发专用的伪机理

### 阶段 4：C12H23 自定义机理
| 项目 | 设置 |
|------|------|
| 机理 | C12H23（用户提供 Chemkin） |
| 组分 | 21 组分，37 步反应 |
| 转换 | ck2yaml → Fuego → mechanism.H/cpp |
| 燃料物性 | 近似正十二烷（C12H26） |
| 当前网格 | 64³，CFL=0.05 |

**状态**：🔄 编译中

### 阶段 5：CVODE 尝试（已放弃）
- 21 组分 CVODE 在 GPU 内存爆炸
- 32³ 网格就 OOM
- 回退 RK64
