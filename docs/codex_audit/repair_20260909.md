# 2026-09-09 独立审查后的修复与复验

本轮针对已确认的越界、错误验收、热点、组分与通量、源项归一化、单位及证据归档问题修复。它不是主计划全部完成声明。历史结果和失败试验均保留；每批修改的原件及前后 SHA-256 在 `repair_backups/`。

## 当前可用与不可用范围

- 修复了 HLLC 的 Array4 组分步长接线、标量 alpha 辅助函数的分量索引、CSF 对未填充状态幽灵层的访问。
- 原 MULES 路径只是人为动量体力，已从主推进删除并在请求时明确拒绝。没有将其他算法重命名为 MULES。
- VOF 混合单元的液相近似闭合与 alpha=0.5 EOS 切换仍是实验模型；PLIC 仍未接入主推进。默认拒绝此路径，`pelec.allow_experimental_vof=1` 仅供开发调试。
- HLLC 星区总能量改为满足能量跃迁关系；stiffened-gas 波速修正包含 p_inf，温度采用零参考能偏移的 `e=cv*T+p_inf/rho`。这不是经标定的真实水物性。
- GPU 热点按域大小定位且初始化检查实际最高温度。WENO 特征积分在 EOS 前进行统一凸限制；异常最终面状态退回有效供体。极低星区压力使用保守稳健通量回退，壁面镜像也同步组分。
- 气相组分面通量使用共同限制因子保持组分通量总和；局部周期输运测试检查非负与守恒。该测试和短时反应算例不构成任意 CFL/网格/反应机理的全局保正证明。
- `shock_droplet` 默认 `heptane_3sp` 保留为非反应输运/破碎基准，反应数为 0 时禁止 `pelec.do_react=1`。显式反应构建选项为 `Chemistry_Model=heptane_lu_88sk`；88 个组分、729 个反应不等于气液爆轰认证。
- AMR/EB 泄漏与点火源按当前层级的有效流体体积归一化，排除细网格覆盖和 EB 固体。制造解只检查积分：单元立方体内流体体积 0.7，1/2/8 MPI rank 一致；未推进实际三维泄漏或火灾。
- 真实 CAD、水密性、现场坐标、储罐实际尺寸及实际三维泄漏/火灾验证按用户要求暂缓。不能用简化几何代替这些证据。

## 单位

PeleC 使用 CGS：压力 dyn/cm²、密度 g/cm³、速度 cm/s、比内能 erg/g、比热 erg/(g·K)、表面张力 dyn/cm、加速度 cm/s²。常用换算：1 Pa=10 dyn/cm²；0.072 N/m=72 dyn/cm；6e8 Pa=6e9 dyn/cm²；4180 J/(kg·K)=4.18e7 erg/(g·K)。无量纲基准必须成套覆盖 EOS、初场、表面张力和重力，不能只改一项。旧泡升案例不因数值存活而升级为真实水/标准基准验证。

## 验收语义

1. 退出码为 0、正常结束、无具体 fatal 标记，只代表进程健康。
2. plotfile 必须保留 Header、所有 Level_*/Cell_H 及实际 FAB 二进制；checkpoint 同样保留全部数据。
3. 所有有效流体单元检查有限值、正密度/温度/压力、组分非负及组分和。当前组分容差为 1e-12，不能用 1e-3 掩盖负质量分数。
4. 热点初场或 H2O 的空间重分布不等于反应：短时 H2/O2 验收额外检查闭合质量预算、净燃料消耗与净产物增加。
5. 前缘使用压力压缩梯度，记录多时刻位置及网格分辨率。两个温度峰位置之差不能作波速；两帧压力位移也不能证明自持爆轰、ZND 精度或胞格统计。
6. 本轮 GPU/MPI 和重启对比属于有限窗口回归；自持爆轰、外部基准、长期稳定和气液胞格认证均未授予。

```bash
python3 tools/check_cfd_run_log.py   --log repair_validation/20260909T164249/gpu_final_np1/run.log   --exit-code "$(cat repair_validation/20260909T164249/gpu_final_np1/exit_code)"
```
