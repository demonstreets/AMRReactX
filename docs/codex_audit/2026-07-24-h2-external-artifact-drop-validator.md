# Engineering H2 External Artifact Drop Validator

Date: 2026-07-24

## Scope

Added `tools/write_engineering_h2_external_artifact_drop_validator.py` as the first validation gate for externally supplied production evidence.

The validator checks the 14 artifacts currently listed by the production blocker closure manifest:

- real-CAD cleanup manifest, source CAD files, cleaned geometry files, data-room index, and cleanup quality record
- SBEPV5 D27 metadata, sensor coordinates, baffle geometry, and experimental time series
- fire calibration metadata, radiation metrics, overpressure metrics, and calibrated consequence report

## Integration

The validator is generated by `tools/rebuild_engineering_h2_evidence_chain.sh`, verified by `tools/verify_engineering_h2_production_evidence.sh`, and included in production evidence schema 26.

## Current State

The default drop directory is scaffolded but intentionally empty of real external data, so the report is expected to remain `NOT_READY-H2-EXTERNAL-ARTIFACT-DROP` with 14 missing or invalid artifacts until controlled evidence is supplied.

## Limitation

This is a pre-ingestion gate. It does not copy external files into the controlled evidence tree and does not clear production blockers by itself.
