# Codex smoke matrix

Updated: 2026-07-21

This matrix records the quick checks that currently prove the repository is not merely parsing files, but can build and run representative minimal cases. These are smoke checks, not validation-quality CFD benchmarks.

## One-command gate

```bash
JOBS=2 RUN_TIMEOUT=120 tools/codex_smoke_all.sh
```

For release/reproducibility-oriented runs, use the wrapper gate:

```bash
SUNDIALS_CUDA_DIR=/home/cj/local/sundials-cuda JOBS=2 RUN_TIMEOUT=180 tools/codex_reproducible_gate.sh
```

Set `CODEX_REPRO_REQUIRE_CUDA=1` to include the PeleC/PeleLMeX CUDA smokes. The script writes detailed logs to `/tmp/codex_smoke_all_<UTC timestamp>/` or to `CODEX_SMOKE_LOG_DIR` when provided.
