# Pele CFD 命令速查与场景矩阵

适用仓库：`/home/cj/my-pele`

这份文档给已经知道目标场景的使用者快速查命令。完整解释见 `从目录到排错_完整运行教程.md`，真实资料交付见 `真实资料投递清单_按文件路径.md`。
