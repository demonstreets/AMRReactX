## 1. 背景与目标

Phase 2.2-2.6 已完成 k-ε 湍流模型及其配套模块（壁面函数、湍流扩散、风场 BC）的单元测试验证。本阶段进行**算例级验证**，确认模块组合后的物理正确性。

选择 CFD 湍流模型验证的经典算例：

| 算例 | 验证内容 | 参考数据 |
|------|---------|---------|
| **平板边界层** (Flat Plate BL) | 对数律速度剖面、壁面摩擦系数 \(C_f\) | Wieghardt & Tillmann (1951), ERCOFTAC |
| **后台阶流动** (Backward-Facing Step) | 分离泡长度、再附点位置、回流区强度 | Driver & Seegmiller (1985), ERCOFTAC |

## 2. 算例一：平板边界层

### 2.1 物理描述

均匀来流掠过光滑平板，从平板前缘开始发展湍流边界层。标准验证：
- 摩擦系数 \(C_f(x)\) 沿流向分布
- 特定站位 \((Re_x)\) 处无量纲速度剖面 \(U^+ = f(y^+)\)

### 2.2 计算域与网格

```
计算域: 0 ≤ x ≤ 2.0 m,  0 ≤ y ≤ 0.3 m
平板:   y=0, 0.05 ≤ x ≤ 2.0 m  (前0.05m为对称面，模拟前缘上游)
```

| 参数 | 值 |
|------|-----|
| 来流速度 \(U_\infty\) | 10 m/s |
| 流体 | 空气，ν = 1.5×10⁻⁵ m²/s |
| 入口湍流强度 | 1%（低湍流度） |
| 网格 | 100×60，壁面第一层 Δy ≈ 5×10⁻⁴ m（y⁺≈1） |
| BC 底面 | 壁面（壁面函数），0.05 ≤ x ≤ 2.0 |
| BC 入口 | 均匀速度 10 m/s + 低湍流 k/ε |
| BC 出口 | 压力出口 |
| BC 顶面 | symmetry |

### 2.3 验证指标

| 指标 | 参考值 (Re_x=10⁶) | 容许误差 |
|------|-------------------|---------|
| \(C_f\) | \(0.027 / Re_x^{1/7} \approx 0.0046\) | ±15% |
| 对数律 \(U^+ = \frac{1}{\kappa}\ln y^+ + B\) | κ≈0.41, B≈5.0 | 斜率 ±10% |
| 边界层厚度 δ₉₉ | 参考 Kármán 积分 | ±15% |

### 2.4 运行参数

```yaml
simulation:
  stop_time: 5.0        # 足够达到稳态
  CFL: 0.5
  max_step: 50000
  
turbulence:
  model: k_epsilon
  wall_function: launder_spalding
  
wind:
  direction: E          # 沿 +x 方向
  speed: 10.0
  reference_height: 1.0
  roughness_length: 1e-5  # 光滑平板
```

### 2.5 数据处理

验证脚本 `tools/validate_flat_plate.py`：
- 提取 x=1.5m 站位的 y⁺, U⁺ 剖面
- 线性回归对数区 (30 < y⁺ < 300)：斜率 1/κ，截距 B
- 提取 \(C_f(x)\) 曲线并与经验公式对比
- 输出对比图 + 偏差表格

## 3. 算例二：后台阶流动

### 3.1 物理描述

来流经台阶突扩，在下游形成分离泡，随后再附。标准验证量：
- 再附长度 \(X_R\)（从台阶面到再附点的流向距离）
- 再附点后速度剖面恢复

### 3.2 计算域与网格

```
计算域: -4H ≤ x ≤ 30H,  0 ≤ y ≤ 9H
台阶:   x=0, y=0 到 y=H (H=0.0381m = 台阶高度)
入口段高度 = 8H（台阶前）→ 扩张到 9H（台阶后）
```

| 参数 | 值 |
|------|-----|
| 台阶高度 H | 0.0381 m (1.5 inch) |
| 扩张比 | 9:8 = 1.125 |
| 来流速度 \(U_{ref}\) | 13.47 m/s（44.2 ft/s 换算，台阶入口中心线） |
| Re_H | 36,000 |
| 网格 | 150×60 |
| BC 入口 | 充分发展湍流剖面（用 Phase 2.6 对数律 + k/ε） |
| BC 台阶面 | 壁面 |
| BC 底面 | 壁面 |
| BC 出口 | 压力出口 |
| BC 顶面 | symmetry |

### 3.3 验证指标

| 指标 | Driver & Seegmiller (1985) | 容许误差 |
|------|---------------------------|---------|
| 再附长度 \(X_R/H\) | 6.26 ± 0.10 | ±15% |
| 台阶面静压系数 \(C_p\) | 参考实验分布曲线 | 形状一致 |
| x/H=4 处速度剖面 | 参考实验数据 | ±10% |
| 摩擦系数 \(C_f\) 沿底面 | 负值区（回流）位置 + 再附后恢复 | 定性正确 |

### 3.4 运行参数

```yaml
simulation:
  stop_time: 1.64        # ~580 对流时间单位 (H/U_ref = 0.0381/13.47 = 2.83e-3 s)
  CFL: 0.5
  max_step: 100000

turbulence:
  model: k_epsilon
  wall_function: launder_spalding

wind:
  direction: E
  speed: 13.47          # 44.2 ft/s 换算
  reference_height: 4.0   # 台阶入口半高
  roughness_length: 1e-5
```

### 3.5 数据处理

验证脚本 `tools/validate_bfs.py`：
- 底面 \(C_f\) 曲线 → 零交叉点 = 再附长度
- 提取多个站位的速度剖面 vs 实验数据
- 提取静压系数 \(C_p\) 沿台阶面分布
- 输出对比图 + 偏差表格

## 4. 验证通过标准

| 条件 | 判据 |
|------|------|
| 平板 \(C_f\) 偏差 | ≤ 15% |
| 平板对数律斜率 | 1/κ ± 10% |
| 后台阶 \(X_R/H\) | 5.3–7.2（6.26 ± 15%） |
| 后台阶回流区存在 | 底面 \(C_f < 0\) 区域长度 > 3H |
| 定性合理 | 速度剖面、\(C_p\) 分布形状正确 |

全部满足 → Phase 2 验证通过，进入 Phase 2.8（着火/燃烧验证）。

## 6. 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| k-ε 已知低估再附长度 | LOW | 15% 容差覆盖此系统性偏差 |
| PeleLMeX 低马赫求解器对湍流算例的稳定性 | MEDIUM | 先用小网格试跑，稳定后再加密 |
| 入口湍流剖面不维持 | MEDIUM | 入口段留 4H 发展区，不够再加 |
| 2D 算例能否模拟 3D 湍流 | LOW | 标准做法，RANS 用 2D 即可 |

## 7. Verdict 自动化

- 部分超出但定性正确 → `VERDICT: PASS WITH NOTES`
- 严重偏离 → `VERDICT: FAIL`
