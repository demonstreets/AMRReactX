# F4/F5 丙烷储区 CFD 三维模型 V2 说明

## 当前状态

已基于以下资料生成第二版 CFD 简化三维模型：

- `F4 总平面布置图 A1.dxf`：用于总平面坐标、管廊、围墙、罐区边界、道路和设备区定位。
- `F5 设备布置图 A3/*.pdf`：用于储罐真实尺寸、设备基础标高、平台标高和局部设备布置。

V2 输出：

- `F4_F5_propane_storage_cfd_model_v2.stl`
- `F4_F5_propane_storage_cfd_model_v2_preview.png`

## V2 相比 V1 的主要升级

V1 主要是把 F4 DXF 中的图层实体直接拉伸成统一高度障碍物。

V2 增加了 F5 PDF 中确认的真实设备尺度：

- `TK-51101`、`TK-51102`：低温丙烷罐，按外罐 `Φ60.0 m × 38.1 m` 建模，基础标高 `EL+2.500 m`。
- `TK-51201`：低温丁烷罐，按外罐 `Φ53.6 m × 34.4 m` 建模，基础标高 `EL+2.500 m`。
- `TK53001` 至 `TK53004`：常温立式罐，按 F4/F5 识别罐径约 `Φ19.7 m`、平台标高约 `EL+23.400 m` 建模。
- `TK53005`、`TK53006`：卧式 LPG 罐，按约 `Φ3.2 m × 17.5 m` 建模。
- BOG/丙烷复热系统：增加 `EL+5.000 m`、`EL+10.000 m` 平台，以及 `C-52001A/B/C` 设备占位。
- 槽车装车站：增加长条装车棚/管廊占位。
- 火炬系统：增加两套圆形火炬/燃烧器区域占位。
- 空压制氮站：增加建筑/设备区占位。

## 置信度说明

高置信度：

- 低温丙烷罐和低温丁烷罐的尺寸、容积、基础标高。
- F4 总图中的管廊、围墙、罐区边界和常温罐组标签位置。

中置信度：

- `TK-51101/TK-51102` 在 F4 总图中的精确中心坐标。原因是低温丙烷大罐在 F4 DXF 中没有以普通 `CIRCLE` 实体直接暴露，疑似在 CAD 块或引用结构里；当前位置由 F4 北侧罐区范围和 F5 设备布置尺寸约束确定。
- BOG 区、装车站、火炬系统内部小设备的精确尺寸。当前按 CFD 障碍物等效模型处理。

仍需补充：

- 泄漏源具体位置、泄漏孔径、方向、高度。
- 丙烷或 LPG 的储存压力、温度、相态。
- 是否考虑低温液态丙烷闪蒸、液池蒸发和两相喷放。
- 风速、风向、环境温度、地面粗糙度。
- 点火位置、点火时间、点火强度。
- 若要做最终真实工程报告，需要原始 CAD 块爆炸/设备坐标表或人工确认储罐中心坐标。

## CFD 使用建议

当前 V2 已适合作为真实厂区障碍物几何的第一版计算输入，用于：

- 丙烷储区泄漏扩散初算。
- 管廊/围墙/大罐障碍物影响分析。
- 点火后火焰传播稳定性算例。
- CPU/GPU/MPI 算例链路真实几何冒烟测试。

不建议直接用于最终事故后果定量报告，除非补齐泄漏工况、气象条件和真实坐标复核。
