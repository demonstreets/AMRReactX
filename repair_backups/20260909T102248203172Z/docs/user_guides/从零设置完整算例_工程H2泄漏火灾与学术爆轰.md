# 从零设置完整算例：工程 H2 泄漏/火灾与学术爆轰

适用仓库：`/home/cj/my-pele`

这份教程只做两件事：选一个工程算例、一个学术算例，从准备文件、改参数、运行到看输出完整走一遍。这里的“从零”不是从空目录重写 PeleC/PeleLMeX，而是在当前仓库已有算例框架上复制模板、改 input、调用已验证脚本。

两个案例目录内也有本地快速教程：

```text
examples/engineering/h2_leak_3d/README_中文快速教程.md

```

## 0. 本教程选定的两个“照做”案例

这份文档固定选两个已经放在仓库里的案例，不再泛泛介绍：

```text
工程案例：examples/engineering/h2_leak_3d
用途：H2 泄漏、扩散、开放区/管廊障碍物、点火、真实反应火焰、CPU/MPI/GPU 验证

学术案例：examples/academic/detonation_2D
用途：PeleC 二维气相爆轰、反应波、AMR 计划、CPU/MPI/MPI+OpenMP 验证
```

从零起一个算例时，你只需要准备三类文件：

```text
1. 算例源码文件
   工程：pelelmex_prob.H、pelelmex_prob.cpp、GNUmakefile
   学术：prob.H、prob.cpp、prob_parm.H、GNUmakefile、Make.package

2. input 文件
   工程：从 input.codex_open_domain_flammable_smoke 复制一份自己的 input
   学术：从 inputs.codex_wave_smoke 复制一份自己的 inputs

3. 可选几何/初值文件
   工程障碍物：STL 文件，管廊着火脚本会自动生成立方体、圆柱和管线 STL
   学术爆轰：ic.txt 可保留，主要初始状态在 inputs/prob.* 参数里改
```

最短流程如下：

```bash
cd /home/cj/my-pele

# 工程泄漏扩散：复制模板 input
cp examples/engineering/h2_leak_3d/input.codex_open_domain_flammable_smoke \
   examples/engineering/h2_leak_3d/input.my_h2_open_domain

# 学术爆轰：复制模板 input
cp examples/academic/detonation_2D/inputs.codex_wave_smoke \
   examples/academic/detonation_2D/inputs.my_detonation_wave
```

然后只改自己的 input，不直接改模板。第一次只改这些项目：

```text
工程 H2：
geometry.prob_lo / geometry.prob_hi       计算域
amr.n_cell / amr.max_step / amr.fixed_dt  网格、步数、时间步
amr.plot_int                              输出间隔
peleLM.lo_bc / peleLM.hi_bc               边界条件
prob.wind_u / prob.wind_v                 环境风
prob.leak_xc / leak_yc / leak_zc          泄漏口位置
prob.leak_rate / leak_radius              泄漏强度和尺寸

学术爆轰：
max_step / stop_time                      步数和终止时间
geometry.prob_lo / geometry.prob_hi       计算域
amr.n_cell / amr.max_level / amr.plot_int 网格、AMR、输出间隔
pelec.cfl                                 CFL
prob.x_split                              初始左右状态分界
prob.p_l / prob.p_r                       左右压力
prob.rho_l / prob.rho_r                   左右密度
```

最常用运行命令放在这里，后文会解释每条命令在干什么：

```bash
# 工程泄漏扩散，CPU 串行
CODEX_H2_LEAK_PROFILE_INPUT=input.my_h2_open_domain \
bash tools/codex_smoke_engineering_h2_leak_open_domain.sh

# 工程泄漏扩散，多核 CPU/MPI

CUDA_VISIBLE_DEVICES=0 \
bash tools/codex_smoke_engineering_h2_pipe_rack_reacting_cuda.sh

# 工程管廊障碍物 + 真实反应火焰，MPI+CUDA+restart 链路
bash tools/codex_smoke_engineering_h2_pipe_rack_reacting_mpi_cuda_restart.sh

# 学术二维爆轰，CPU 串行
bash tools/codex_smoke_academic_detonation_wave.sh

# 学术二维/三维 PeleC 后端，多核 CPU/MPI
MPI_RANKS=4 bash tools/codex_smoke_academic_pelec_mpi.sh

# 学术 PeleC CUDA 后端，单 GPU

```

```bash

grep -RniE "nan|inf|abort|backtrace|cvode|cuda error|segmentation" /tmp/codex_* | tail -n 80

# 3. 是否生成 plotfile
find /tmp/codex_* -maxdepth 4 -type d -name "plt[0-9][0-9][0-9][0-9][0-9]" | sort | tail
```

## 1. 工程算例：H2 开放区域泄漏扩散

代表目录：

```text
examples/engineering/h2_leak_3d
```

这个目录包含：

```text
GNUmakefile                  编译入口
pelelmex_prob.H              PeleLMeX problem 参数声明
pelelmex_prob.cpp            泄漏源项、云团、障碍物等 problem 逻辑
input.codex_open_domain_flammable_smoke  开放区域 H2 泄漏扩散模板
```

### 1.1 准备自己的 input 文件

不要直接改模板，先复制一份：

```bash
cd /home/cj/my-pele
cp examples/engineering/h2_leak_3d/input.codex_open_domain_flammable_smoke \
   examples/engineering/h2_leak_3d/input.my_h2_open_domain
```

打开并编辑：

```bash
sed -n '1,220p' examples/engineering/h2_leak_3d/input.my_h2_open_domain
```

最先改这几组参数。

计算域：

```text
geometry.prob_lo = 0.0 0.0 0.0
geometry.prob_hi = 2.0 1.0 1.0
```

网格和步数：

```text
amr.n_cell = 32 16 16
amr.max_level = 0
amr.max_grid_size = 32
amr.max_step = 100
amr.fixed_dt = 1.0e-3
amr.plot_int = 20
amr.check_int = -1
```

边界条件：

```text
peleLM.lo_bc = Inflow SlipWallAdiab SlipWallAdiab
peleLM.hi_bc = Outflow SlipWallAdiab SlipWallAdiab
```

泄漏和环境风：

```text
prob.wind_u = 2.0
prob.wind_v = 0.0
prob.leak_xc = 0.5
prob.leak_yc = 0.5
prob.leak_zc = 0.5
prob.leak_rate = 2.0e-3
prob.leak_radius = 0.15
prob.leak_vel_x = 2.0
prob.leak_T = 300.0
```

物理开关：

```text
peleLM.user_defined_ext_sources = 1
peleLM.do_react = 1
peleLM.chem_integrator = ReactorNull
eb2.geom_type = all_regular
```

这里 `ReactorNull` 表示这个开放区域算例用于泄漏、扩散和可燃云团，不做真实火焰反应。后面的管廊着火算例会使用真实反应。

### 1.2 串行 CPU 运行

运行自定义 input：

```bash
cd /home/cj/my-pele
CODEX_H2_LEAK_PROFILE_INPUT=input.my_h2_open_domain \
bash tools/codex_smoke_engineering_h2_leak_open_domain.sh
```

脚本会自动：

```text
1. 编译 examples/engineering/h2_leak_3d
2. 把 input.my_h2_open_domain 复制到 /tmp/.../run/
3. 运行 PeleLMeX
4. 生成 plotfile
5. 检查 H2 云团、可燃体积、hazard planes 和时间序列
```

### 1.3 多核 CPU/MPI 运行

2 个 MPI rank：

```bash
cd /home/cj/my-pele
MPI_RANKS=2 CODEX_H2_LEAK_PROFILE_INPUT=input.my_h2_open_domain \
bash tools/codex_smoke_engineering_h2_leak_open_domain_mpi.sh
```

4 个 MPI rank：

```bash

MPI_RANKS=4 CODEX_H2_LEAK_PROFILE_INPUT=input.my_h2_open_domain \
bash tools/codex_smoke_engineering_h2_leak_open_domain_mpi.sh
```

如果 MPI rank 增加后效率变差，先减小 `amr.max_grid_size`，让网格块数足够分给更多 rank。

## 5. 改大算例的顺序

不要一上来同时改大域、细网格、AMR、强点火和多卡。推荐顺序：

```text
1. 复制模板 input。
2. 只跑 1 到 20 步。
3. 确认串行 CPU 过。
4. 再跑 CPU/MPI。
5. 再跑单 GPU。
6. 再开更长时间、更细网格或 AMR。
7. 最后才尝试 MPI+CUDA、多卡或真实 CAD。
```

每次改完 input 后先查：

```bash
grep -nE "max_step|n_cell|max_level|max_grid_size|plot_int|do_react|chem_integrator|leak|ignition|prob\\." \
  examples/engineering/h2_leak_3d/input.my_h2_open_domain
```

或：

```bash
grep -nE "max_step|n_cell|max_level|max_grid_size|plot_int|do_react|chem_integrator|prob\\." \
  examples/academic/detonation_2D/inputs.my_detonation_wave
```
